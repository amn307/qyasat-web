# Qyasat CMS

منصة قياسات لإدارة المحتوى، تنظيم الصفحات، قياس الأداء، وتجهيز بنية رقمية قابلة للتطوير.

## معلومات المشروع

- Repository: Moamenfz/Qyasat_CMS
- Package: qyasat-cms
- Framework: Next.js
- Default branch: main

## التشغيل المحلي

npm install
npm run dev

## البناء

npm run build

## ملاحظة
